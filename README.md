# FureZ Tracker

Telegram Mini App для тренировок и питания: программы с недельным расписанием,
запись подходов с таймером отдыха и рекордами, дневник питания с базой продуктов,
вес тела и графики прогресса.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173/FureZTracker/
npm run build
npm run deploy   # GitHub Pages
```

Вне Telegram приложение тоже работает: кнопки Telegram (Back/Main) заменяются
обычными кнопками на странице.

## Устройство

- `src/data` — хранение в `localStorage`, миграция со старого формата v2, библиотека упражнений, база продуктов, действия над состоянием
- `src/lib` — даты, расчёт КБЖУ, статистика тренировок, поиск в Open Food Facts
- `src/screens` — вкладки: Сегодня, Тренировки, Питание, Прогресс
- `src/sheets` — экраны поверх вкладок: тренировка, программа, поиск еды, профиль и т. д.
- `src/telegram.js` — обёртка над Telegram WebApp SDK (тема, BackButton, MainButton, вибрация)

Данные хранятся только на устройстве; в профиле есть экспорт и импорт бэкапа.
